# 2.3.6 → 2.3.7 升级与 NVENC 复测

2026-10-19，在原 macOS 15.8.1 / 24H32、Intel Unraid VM、20 vCPU、RTX 3060 12GB（PCI `10de:2504`）完成升级。**2.3.7 + 指定 NVENC 候选在复测中通过，已保留安装，没有回滚。** 本轮只更新驱动，macOS 26 尚未升级或验收。

## 为什么先更新驱动

[上游 2.3.7 发布说明](https://github.com/nullmoth/nvidia-macos-driver/releases/tag/v2.3.7)列出视频解码输入边界、内核映射、固件权限和安装器私有副本等安全修复，也包含窗口拖动与 macOS 26 图标 / Liquid Glass 修复。这些是上游说明；本次实机范围仍限于 15.8.1 上的显示与 H.264 NVENC。

## 实际执行顺序

1. 核对当前 2.3.6 + NVENC 的主插件、编码库摘要及 macOS 版本，保存配置与 NVRAM。正常关闭 VM，确认 `shut off` 后保存系统 qcow2、实际 EFI raw、交付盘、UEFI NVRAM、VM XML；系统盘 `qemu-img check` 无错误。该份新备份包含可用的 **2.3.6 + NVENC**，此前 1.9.0 备份也保留。
2. 固定官方 2.3.7 tag、commit、269039968 字节包及 SHA。比较新旧二进制、反汇编和源代码；完成本地 14 项实物适配测试，包含布局机器码差分和独立汇编复现。
3. Actions 对 2.3.6 / 2.3.7 分别运行静态测试，构建签名候选，并对精确官方输入执行适配测试和无 NVIDIA runner 的负向测试。目标 Mac 收到包后再次核对 SHA。
4. 官方 `CHECK=1` 预检通过，测试内核集合包含四个扩展；随后运行官方安装器并第一次重启。确认 NVRM、NVRMFB、NVRMAGDC、NVAccel 均加载 2.3.7，Metal 3 与 VNC 正常。
5. 固件成功迁入 `/Library/NullMoth/nvfw`，目录 root 所有、无组和其他用户写权限，旧 `/Users/Shared/nvfw` 已清除。保留既有 EFI / Apple 账户身份配置与 `gfxrst=4`，本轮未改 OpenCore。
6. 覆盖工具在目标机通过单卡 PCI、已加载内核和完整官方 bundle 校验，备份官方 2.3.7 用户态 bundle 后原子应用候选。核对签名及两个二进制摘要，第二次重启。
7. 使用同次 Actions 的原样预编译 v2 探针，先短测，再停止光梭后台完成持续测试；报告以候选压缩包、实际加载编码库及 tag 三者绑定。第二轮末段另行启动光梭生产编码路径短测，两者均通过；测试结束恢复光梭后台。桌面及其他应用负载未隔离，不作受控性能对比。

## 验收结果与首轮未达标记录

输入为普通 NV12、1920×1080、60 FPS，目标码率请求 20 Mbps，未统计实际输出码率。编码端要求硬件，固定精确 NVENC ID；软件解码仅用于独立核对图像，沿用 [v2 报告的显式禁硬件解码证据](hardware-acceptance.md#软件解码证据与报告版本)。

| 项目 | 首轮持续测试 | 第二轮持续测试 |
| --- | --- | --- |
| 正式资格结果 | 未通过：持续性能低于门槛 | 通过 |
| 编码 / 解码 / 像素通过帧数 | 3600 / 3600 / 3600 | 3600 / 3600 / 3600 |
| 总耗时 / 合成吞吐 | 65.067 s / 55.328 FPS | 59.997 s / 60.003 FPS |
| NVENC 编码 p50 / p95 / 最大 | 2.882 / 4.070 / 19.036 ms | 2.513 / 2.776 / 5.530 ms |
| 回调错误 / 丢帧 | 0 / 0 | 0 / 0 |
| 强制 IDR | 60 / 60 | 60 / 60 |

首轮在重启后约两分钟进行，记录到较高系统负载；第二轮沿用同一候选、探针、参数和验收门槛。总耗时还包含填图、CPU 软件解码、约 311 万 Y/UV 像素比较及线程调度，所以首轮 55.33 FPS 不能单独归因为 NVENC 编码器退步。没有阶段计时或受控 A/B，因此启动负载是可能因素，不宣称已确定根因。

第二轮像素误差最大值：Y MAE 0.0681、UV MAE 0.0410、区域 MAE 0.0977、细线 0.6747、标记 2，均在既有容差内。30 帧短测也通过。光梭现有生产路径自测完成 30 帧、零错误，实际选择 `hardware` / `com.nvmtl.videoencoder.avc.nvenc`，解码内容通过；旧版输入排列补偿关闭，编码高度 1080。测试结束已恢复光梭后台，确认 UDP 47990、VNC 5900、1080p 显示和 Metal 3 正常。

公开证据包含 [短测](../reports/2026-10-19-v2.3.7/smoke.json)、[首轮持续测试原始报告](../reports/2026-10-19-v2.3.7/qualification-initial.json)、[第二轮持续测试原始报告](../reports/2026-10-19-v2.3.7/qualification-retry01.json)、[光梭自测摘要](../reports/2026-10-19-v2.3.7/glidebeam-selftest-summary.json) 及 [来源记录](../reports/2026-10-19-v2.3.7/provenance.json)。短测和第二轮均通过带候选 SHA、编码库 SHA、tag 的正式校验器；首轮失败保持原样。所有公开 JSON 的原始字节摘要在 [SHA256SUMS.txt](../reports/2026-10-19-v2.3.7/SHA256SUMS.txt)。

本次通过只覆盖这一组二进制和合成工作点，不代表冷启动负载下始终达到 60 FPS，不保证光梭网络、客户端呈现或浏览器内容帧率。HEVC 未启用，其他显卡和未来候选未获资格。

## 备份和恢复的边界

官方安装器保存的升级前驱动仅作附加恢复途径；`lastgood` 是一次性的，基础显示成功后会退出，也不检测编码或像素错误。它不能保障后续覆盖包测试失败时自动恢复。

安装器打印的 `uninstall.sh "$BK"` 在此版仍不负责还原完整旧驱动，不当作回滚命令。仅撤销覆盖包可用覆盖工具 `--restore` 恢复同版本官方用户态 bundle 并重启；恢复可用的旧 **2.3.6 + NVENC** 则应使用新保存的完整离线 VM 备份，保持关机、保留失败状态后恢复系统盘、EFI 和 NVRAM。私有回滚脚本已随该备份保存。

上述 15 验收结果不自动转移至 macOS 26。当时机器使用 `iMacPro1,1`，此前 Apple 账户修补只限定 Darwin 24；26 的 SMBIOS / 引导、Darwin 25 内核补丁、专用 NVAccel 和系统升级后内核集合切换均需另行审阅。以下另记后续实际升级结果。

## 同日后续：隔离 macOS 26 实测

在保留原 15 关机和完整冷备的前提下，独立克隆实际升级至 **26.7.1 / 25G241 / Darwin 25.6.0**。已有身份保留，旧 Darwin 24 Apple ID 字符串修补只在克隆成对禁用，改用 RestrictEvents `sbvmm`；没有将旧补丁扩大到 Darwin 25。实际 26 上安装官方 os26 NVAccel / AuxKC、加载基础 NVRM 后，才通过保护检查并应用固定 NVENC 候选。

候选资产 SHA256 为 `e6171560048fc8ebcdc061360ec79aa4d8100bb4f6d994946aaa11d2e3c90f4e`，编码库为 `36a3d6a7ddb5d057afc0b66016f1dbfa597c4ee1aeb48c0bc9a1841de37b0830`。Metal 复制 / 计算 / 渲染零错误；3600 帧全部编码、独立解码并校验像素，**60.004018745 FPS、编码 p95 3.502125 ms**；光梭 30 帧生产硬编像素和正常重启后复验通过。用户确认光梭实际连接和控制正常，最终正常关机、完整冷备和再次冷启动完成。

完整过程、各次外层检查失败与纠正、GUI / USB 输入修复及恢复边界见[固定版本的升级教程](https://github.com/dixtdf/unraid-macos-rtx3060/blob/0a1c3e0ca374d3653b23b83da058358faf2270d3/docs/15-macos26-upgrade.md)与[脱敏结果](https://github.com/dixtdf/unraid-macos-rtx3060/blob/0a1c3e0ca374d3653b23b83da058358faf2270d3/results/observed-2026-10-19-tahoe26-upgrade.json)。同盘 reflink 不是抗物理磁盘故障的异地备份；26 原生 VNC 取帧仍超时，音频内容、Apple ID 重新登录、HEVC 及其他图形 API 未复验。这里没有另发新候选或将本次结果泛化成全平台支持。
